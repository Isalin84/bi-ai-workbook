# Рабочая тетрадь «Нейросети для Boehringer Ingelheim»

Интерактивная тетрадь практикума по генеративным нейросетям для сотрудников российского
представительства Boehringer Ingelheim. Ведёт Иван Салин, Best Practice.

- Тетрадь: `https://isalin84.github.io/bi-ai-workbook/`
- Табло ведущего: `https://isalin84.github.io/bi-ai-workbook/tablo.html`

Один файл `index.html`, без сборки и внешних библиотек. Открывается и с сайта, и с диска двойным кликом.
Все ответы и баллы участника живут в его браузере (localStorage), никуда не отправляются.

## Что в папке

| Путь | Что это |
|---|---|
| `index.html` | Тетрадь целиком: контент, движок баллов, звуки, диплом |
| `tablo.html` | Табло ведущего: вставить коды участников, построить рейтинг, показать победителей на проекторе |
| `assets/` | Логотипы Best Practice и Boehringer Ingelheim (в HTML они вшиты base64, файлы здесь для справки) |
| `assets/illustrations/` | Слоты для иллюстраций блоков и диплома: `b0-start.webp … b7-final.webp, slovar.webp, diploma.webp`. Файлов может не быть, тетрадь работает без них |
| `data/` | Учебные датасеты: реестр обучений GxP (CSV + XLSX) и медиа-упоминания (CSV). Данные выдуманы, фамилии в них синтетические |
| `examples/` | Эталонные мини-приложения: дашборд по реестру обучений и обезличиватель для фармы (текст + таблицы) |
| `print/` | Памятка по безопасности и каталог нейросетей на печать, А4 |
| `docs/` | Локальная копия Кодекса поведения BI на случай, если сайт не откроется. В репозиторий не попадает (`.gitignore`) |

Генераторы лежат вне репозитория, в `../_tools/`: `gen_pharma_data.py` (датасеты, seed фиксирован),
`gen_catalog_print.js` (каталог на печать собирается из массива `CATALOG` в `index.html` - руками не править,
запускать `node _tools/gen_catalog_print.js`).

## Как проходит день

1. **До семинара.** Письмом за неделю: зарегистрироваться в Qwen, Kimi, Arena; по желанию Leonardo и Suno.
   Попросить ИТ клиента проверить из корпоративной сети: `isalin84.github.io`, `chat.qwen.ai`, `kimi.com`,
   `arena.ai`, `leonardo.ai`, `suno.com`, `fonts.googleapis.com`. Если github.io закрыт - тетрадь раздаётся
   папкой на флешке, работает с диска.
2. **Блок 0.** Участник заполняет профиль (имя, должность, отдел, «чем занимаюсь») - эти данные подставляются
   во все промпты и в диплом. Отмечает регистрации.
3. **По ходу дня** ведущий называет кодовые слова. Участник вводит их в «Справочник» (кнопка в шапке).
   Проверка терпима к регистру, Ё и раскладке клавиатуры: «byutkm[fqv» засчитается как ИНГЕЛЬХАЙМ.
4. **Блок 7.** Участник нажимает «Сформировать код» и отправляет строку в чат группы.
5. **Табло.** Ведущий вставляет всё содержимое чата в `tablo.html` (мусор отбрасывается сам, дубли схлопываются
   по большему баллу), нажимает «Показать на проекторе». Пробел, → , Enter или кликер - следующая стадия:
   3 место → 2 место → 1 место с фанфарами и конфетти → все участники. Esc - закрыть. CSV выгружается кнопкой.
6. **Диплом.** Собирается в блоке 7 в цветах Boehringer Ingelheim, скачивается PNG или печатается в PDF.

## Что спрятано в данных

**Реестр обучений GxP** (264 строки, 120 сотрудников, 13 подразделений, 8 курсов, июль–декабрь 2025):
1. «Медицинские представители» - 54 % всех просрочек, доля просроченных у них 26 % против 10 % у остальных.
2. Курс «Информационная безопасность» просрочен в 32 % случаев против 13 % по другим курсам (срок всего 30 дней).
3. Декабрь - пик: 24 просрочки против 8 в ноябре.

**Медиа-упоминания** (180 строк, март 2025 – февраль 2026, 10 вымышленных изданий):
1. Сентябрь 2025 - доля негатива 56 % против 11 % в остальные месяцы, тема «доступность и цены».
2. «Деловой курьер» - среднее время ответа 43 часа против 12 у остальных.
3. Запросы в выходные отвечают в 2,8 раза дольше, чем в будни.

Задание в тетради принимает ответ, если в нём есть слова-маркеры находок (см. `keys` в задачах `find_reg`
и `find_media`). Перед проверкой участник подтверждает, что удалил ФИО из файла; если в ответе нейросети
проскочила фамилия или телефон - проверка не пропустит.

## Как править

Контент живёт в массивах в начале `<script>` в `index.html`:
`CATALOG` (сервисы), `DOCS` (Кодекс), `GLOSSARY` и `GLOSSARY_EXTRA` (словарь), `IMAGE_PROMPTS` (три промпта
для картинок), `ANTOSHKA_LYRICS` и `MUSIC_GENRES` (Suno), `BLOCKS` (все блоки и задания), `CODES` (кодовые слова),
`LEVELS` (уровни). Дальше по файлу: `ROLES`/`DEPTS` (подсказки в профиле), `BF` (пример формулы промпта),
`PII` (что ловит проверка на персональные данные), `PALETTE` и `appPrompt()` (промпт дашборда),
`SYS_BASE`/`CTRL_ROLE`/`SYS_DEPT` (ассистенты). Поменяли текст в массиве - поменялась страница.

Сумма баллов заданий в блоке должна совпадать с `pts` блока. Проверка:

```bash
node -e "const s=require('fs').readFileSync('index.html','utf8');const a=s.indexOf('var CATALOG=['),b=s.indexOf('/* ================================ ЯДРО');const B=new Function(s.slice(a,b)+';return BLOCKS')();console.log(B.reduce((x,y)=>x+(y.pts||0),0));B.forEach(b=>console.log(b.id,b.pts,b.tasks.filter(t=>t.pts).reduce((x,t)=>x+t.pts,0)))"
```

## Технические заметки

- Звуки синтезируются через Web Audio, файлов нет. Кнопка «Звук» в шапке, состояние запоминается.
  Звук включается только после первого клика на странице - так требует браузер.
- Конфетти рисуется на canvas без библиотек; выключено для пользователей с «уменьшить движение».
- Диплом рисуется на canvas 1754×1240 после загрузки Montserrat (ждём до 1,5 с, потом рисуем системным шрифтом).
  Если положить `assets/illustrations/diploma.webp`, картинка встанет в правую колонку вместо трёх плашек.
- Шрифты грузятся с Google Fonts; без сети подставляются системные, всё работает.
- Ключ localStorage тетради `bi_pharma_wb_v1`, табло `bi_tablo_v1` - не пересекаются со старой тетрадью солодовни.
